How does Python's GIL affect threading?
The Global Interpreter Lock lets only one thread execute Python bytecode at a time[1], so CPU-bound threads see little speedup. I/O-bound work still benefits, since the GIL is released during blocking I/O[2]. For true parallelism, use multiprocessing[3].
